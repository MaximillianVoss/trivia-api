# Trivia API — условие

Краткий русский пересказ задания курса; исходные скриншоты и переписка сюда не включены. **3 балла**: получение и отображение вопроса — 2, обработка ограничения частоты — 1.

## Обязательные требования

1. Создать React-приложение, получающее один случайный вопрос с Open Trivia DB: `https://opentdb.com/api.php?amount=1`.
2. До первого запроса показывать приглашение нажать кнопку.
3. Загружать вопрос только при нажатии пользователем, а не автоматически при открытии страницы.
4. После успеха заменить приглашение вопросом.
5. При HTTP 429 показать понятное сообщение о необходимости немного подождать.

Точные обязательные строки интерфейса сохранены в реализации и автоматических тестах: начальное приглашение и сообщение при ограничении частоты. Лимит API — одна попытка каждые 5 секунд на IP.

## Самостоятельная проверка без подсказки решения

- Есть ли запрос к API сразу после открытия?
- Что происходит при первом и повторном нажатии?
- Что увидит пользователь при медленном соединении?
- Как отличить HTTP 429 от сетевого сбоя?
- Можно ли прочитать вопрос, содержащий HTML-сущности?

Показ ответа, тайм-аут, индикатор загрузки и декодирование HTML-сущностей — дополнительные улучшения, не отдельные обязательные пункты.
